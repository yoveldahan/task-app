# ראס – ניהול משימות, פרויקטים ולקוחות

אפליקציית ווב (React + TypeScript + Vite) בעברית מלאה, מותאמת לנייד ולמחשב. הנתונים נשמרים אוטומטית ב-`localStorage` של הדפדפן.

## הרצה

```bash
npm install
npm run dev        # http://localhost:5173 (נגיש גם מהרשת המקומית)
npm test           # בדיקות המפענח והתאריכים
npm run build      # בנייה ל-dist/ – אתר סטטי שאפשר להעלות לכל אחסון
```

## שימוש מהטלפון

הדרך המומלצת: להעלות את `dist/` לאחסון סטטי עם HTTPS (Netlify / Vercel / GitHub Pages / Cloudflare Pages),
לפתוח בטלפון ולבחור "הוסף למסך הבית". HTTPS נדרש להכתבה קולית, להתראות ולהתקנה כאפליקציה.

## סנכרון ענן (Supabase)

1. ב-Supabase: SQL Editor ← הדבק את `supabase/schema.sql` ← Run (יוצר טבלאות, הרשאות RLS ו-Realtime).
2. Authentication ← URL Configuration: להגדיר את Site URL לכתובת האתר ב-Netlify (לקישור אישור האימייל).
3. באפליקציה: הגדרות ← סנכרון ענן ← הרשמה, אישור האימייל, התחברות. להתחבר קודם במכשיר עם הנתונים העדכניים.

המכשיר שומר עותק מקומי ועובד גם בלי קליטה; שינויים נשמרים בתור ומסונכרנים כשהחיבור חוזר.
גיבוי JSON ממשיך לעבוד כגיבוי עצמאי.

## הזנה מהירה

- `נושא לישיבה: ...` ← נכנס למסך "נושאים לישיבה" ליום ראשון הקרוב.
- כל טקסט אחר ← משימה. מזוהים אוטומטית: לקוח (גם עם אותיות שימוש: "לאושר עד"), פרויקט קיים,
  "פרויקט חדש: <שם>", איש צוות ("מתן", "תקוע אצל הלקוח"), תאריך ("היום", "מחר", "יום ראשון", "5/11", "בשבוע הבא")
  ושעה ("ב-10:00", "בשעה 3") ← מועד ביצוע ותזכורת.
- קישור `?quickAdd=<טקסט>` מוסיף פריט מקיצור דרך בטלפון או מ-Gemini. באנדרואיד, אחרי התקנה למסך הבית,
  אפשר גם "שיתוף" של הודעת וואטסאפ ישירות לאפליקציה.

## הזנה מבחוץ

- **קישור:** `https://yoveltask.netlify.app/?task=להתקשר&client=פז&due=מחר&time=10:00&who=מתן`
  (גם `topic=` לנושא לישיבה, `project=`, `reason=`, ו-`prefill=1` כדי רק למלא את תיבת ההזנה).
- **Webhook:** `POST /api/tasks` עם `Authorization: Bearer <WEBHOOK_TOKEN>` וגוף JSON
  (`text`, `topic`, `client`, `project`, `due`, `time`, `who`, `reason`, `dryRun`). פירוט מלא בראש
  `netlify/functions/add-task.mts`.
- משתני סביבה ב-Netlify (scope: Functions): `WEBHOOK_TOKEN`, `SUPABASE_SECRET_KEY`, `SUPABASE_USER_ID`.
  אחרי שינוי משתנים יש לפרוס מחדש.

## מבנה

- `src/lib/` – מודל נתונים, store, סנכרון (`sync.ts`, `syncCore.ts`), מפענח, תזכורות, ייצוא.
- `supabase/schema.sql` – סכמת מסד הנתונים.
- `src/views/` – ארבעת המסכים. `src/components/` – רכיבים משותפים.
