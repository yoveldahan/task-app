# המשימות שלי – ווידג'ט אנדרואיד

אפליקציה קטנה עם ווידג'ט למסך הבית שמציג את המשימות הפתוחות מאותו חשבון שבאתר.

## התקנה

1. בטלפון: **הגדרות ← אבטחה (או "אבטחה ופרטיות") ← התקנה ממקורות לא מוכרים**. אשר את ההתקנה לאפליקציה שמשמשת להורדה (דפדפן או מנהל הקבצים).
2. העתק את `app-release.apk` לטלפון והקש עליו. אשר את ההתקנה.
3. פתח את **המשימות שלי** והתחבר עם האימייל והסיסמה של האתר.

## הוספת הווידג'ט למסך הבית

1. לחץ והחזק על מקום פנוי במסך הבית.
2. בחר **ווידג'טים** ואז **המשימות שלי**.
3. גרור את הווידג'ט למסך הבית. הוא ייטען מיד.

הווידג'ט מתרענן לבד כ-15 דקות, וגם בכל פעם שמוסיפים אותו. לחיצה על הווידג'ט פותחת את האפליקציה.

## בנייה מהמקור

דרישות: JDK 17, Android SDK עם platform 36 ו-build-tools, ו-`local.properties` עם `sdk.dir`.

```bash
cd android
./gradlew :app:testDebugUnitTest   # בדיקות
./gradlew :app:assembleRelease     # APK חתום, בתיקייה app/build/outputs/apk/release/
```

החתימה נקראת מ-`keystore.properties` (ראה להלן). בלי הקובץ הזה ה-APK לא ייחתם.

## חתימה (keystore)

הקבצים הבאים **אינם בגיט** (מוגדרים ב-`.gitignore`):

- `keystore/release.jks` – מפתח החתימה
- `keystore/keystore-password.txt` – הסיסמה של המפתח
- `keystore.properties` – מפנה לקבצים האלה (לא מכיל את הסיסמה עצמה)

שמור עותק בטוח של שלושתם. בלי המפתח לא ניתן לעדכן את האפליקציה מאותה חתימה בטלפון.

## מבנה

- `app/src/main/java/com/ras/tasks/domain/` – מודל המשימה, סינון ומיון (נבדק ביחידה)
- `data/` – חיבור ל-Supabase, שאילתה, ושמירת הנתונים שהווידג'ט מציג
- `auth/` – שמירת ההתחברות מוצפנת במכשיר
- `work/` – רענון כל 15 דקות ורענון מיידי בהוספת הווידג'ט
- `widget/` – הווידג'ט (Jetpack Glance)
- `ui/`, `MainActivity.kt` – מסך התחברות
